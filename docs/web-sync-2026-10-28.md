## Phạm vi theo yêu cầu

Đợt đầu bỏ qua thanh toán theo ghi chú của người dùng. Theo yêu cầu rà lại tiếp theo, đã bổ sung luồng Premium ở `/premium`: xem gói từ server, chọn payOS/MoMo theo cấu hình, xác nhận và mở trang thanh toán bằng trình duyệt hệ thống. Lưu đơn theo tài khoản để mở lại/kiểm tra sau khi khởi động lại app; chỉ trạng thái PAID từ server mới cập nhật quyền lợi. Khi quay lại app hoặc đóng trình duyệt, kiểm tra đơn tối đa 10 lần, cách nhau 3 giây. Backend hiện trả về trang account trên web, nên app hướng dẫn người dùng đóng trang thanh toán để quay lại; không tự giả định đã tích hợp native return URL. Các thay đổi SEO, sitemap, robots, chú thích bản đồ API và trang giới thiệu chỉ dành cho web không tạo thêm màn native. Mobile không có route `/hoc-thu` cũ; khách vẫn học bài trực tiếp qua lộ trình.

## Lỗi chạy mobile đã xử lý cùng đợt

Bản native đã cài thiếu `ExponentImagePicker`. Đã tạo lại và cài APK có module chọn ảnh; bổ sung peer dependency `expo-asset`, đồng bộ các gói theo Expo SDK 58. Lệnh `npm run dev` ghi dấu phiên bản cấu hình trên từng thiết bị để tự build lại khi thư viện/config đổi. API có timeout và chuẩn hoá URL để tránh chờ vô hạn lúc khởi động.
